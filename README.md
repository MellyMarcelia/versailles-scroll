# Carnet de Versailles

A scroll-driven walk through the Palace of Versailles — the gate, the Hall of Mirrors,
Marie Antoinette's bedchamber and the gardens — drawn as a watercolour sketchbook.
Scroll forward to walk in, scroll back to walk out.

**Live site:** _coming soon_

## Project files
- `PLAN.md` — Step 1: subject, visual direction, technical plan, research, budget
- `prompts/prompts.md` — style block and every image/video prompt
- `TEST_RUN.md` — Step 2: the Gate → Hall test transition through Magnific MCP
- `scripts/frames.sh` — extract first/last frames for transition keyframes
- `scripts/seamcheck.sh` — measure seams and build a joined preview
- `scripts/encode.sh` — encode clips for scrubbing + WebP posters
